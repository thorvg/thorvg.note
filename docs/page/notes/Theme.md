# Dark / Light mode

Change the appearance while you write.
Click inside this editor to try it.

## Switch themes

1. Press **F1** to open the command palette.
2. Type `switch`.
3. Select **Switch light / dark theme**.
4. Press **Enter** to apply it.

Repeat these steps to switch back.

## Choose an appearance

- For dark mode, press **F1**, type `dark`,
  and select **Use dark appearance**.
- For light mode, press **F1**, type `light`,
  and select **Use light appearance**.

Use **Up / Down** to select a command,
then **Enter** to run it. **Escape** closes the palette.

## Another shortcut

**Ctrl + Shift + P** also opens the command palette.
On macOS, use **Command + Shift + P**.

> Each demo has its own appearance.
> Try switching either editor independently.
