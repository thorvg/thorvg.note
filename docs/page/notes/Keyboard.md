# Keyboard

Mod is Command on macOS and Ctrl everywhere else, in the browser too.

  F1            Command palette
  Mod+P         Recent files
  Mod+O         Find a file
  Mod+S         Save
  Mod+B         Show or hide the library
  Mod+,         Settings
  Mod+Z         Undo
  Mod+Shift+Z   Redo
  Mod+A         Select all
  Mod++ Mod+-   Editor font size

Click inside the app first: it only hears the keyboard while it has focus.
A browser keeps a few keys for itself, such as new window and close tab.
The command palette reaches every command either way.
